# Security

Please report a vulnerability privately, through
[GitHub's reporting form](https://github.com/emilystap/groovehound/security/advisories/new),
rather than in a public issue.

Groovehound is a personal project, so there's no response time I can promise, but reports are
welcome and I'll fix what I can. Only the latest image (`ghcr.io/emilystap/groovehound:latest`)
gets fixes.
